# Portafolio — Dilan Fonseca

One page personal como carta de presentación técnica: perfil, habilidades, trayectoria, proyectos destacados y contacto.

## Tecnologías

- HTML5 semántico
- CSS3 (variables, `clamp()`, media queries responsive)
- JavaScript (carrusel de proyectos, formulario, selector de idioma ES/EN)
- Tipografías: Space Grotesk, Inter, JetBrains Mono
- SEO: meta tags, Open Graph, Twitter Card, `schema.org` Person, `sitemap.xml`, `robots.txt`

## Proyectos destacados

- **DeliveryBot** — sistema de pedidos vía bot de Telegram con IA (Gemini), n8n y Google Sheets.
- **Gestión de Producción ACME** — sistema de inventario y producción con JavaScript y Firebase.
- **Fundación Patitas Felices** — sitio web institucional con HTML5 y CSS3.

## Características

- Diseño responsive (móvil, tablet, escritorio)
- Selector de idioma ES/EN
- Carrusel de imágenes por proyecto con navegación por flechas y puntos
- Formulario de contacto
- Accesibilidad: skip link, `focus-visible`, `aria-label` en navegación e imágenes
- Imágenes optimizadas en formato WebP
